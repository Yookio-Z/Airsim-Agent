# NOTES.md —— Agent 的长期笔记（每轮自动注入）

这是**操作员维护的知识文件**：每次任务开始时，
本文件会连同 `SYSTEM.md` 一起自动注入规划器与 Agent Loop 的上下文。所以只写
"以后每次都用得上"的东西，保持简短。

适合写：
- 环境事实：目标区域在哪、有什么参考物、常去的坐标与高度；
- 机队事实：载具清单、谁装了相机、常用巡航速度；
- 经验教训：这一类指令以前踩过什么坑（比如果树区不要低于 3 m）。

不要写：
- 单次任务的经过——运行结束时运行时会自动写入任务日记（`memory.json` / `runs/`）；
- 成段的操作流程——那是 `.airsim_agent/skills/<name>/SKILL.md` 的职责。
